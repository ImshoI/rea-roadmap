Best order to learn

1. Install REA → 2. Do Notes Export → 3. Break down Notion as an Electron app → 4. Solve a CTF binary → 5. Investigate the Aegis APK → 6. Recreate one function from DX-Ball → 7. Only then go to Ghidra, assembly and papers

No need to read everything in order. The whole path:
APP → ONE FEATURE → REA EVIDENCE → CLEAN SPEC → LOCAL REBUILD → TEST AGAINST ORIGINAL
